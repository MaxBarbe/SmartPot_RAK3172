# Crédits et provenance

## Projet SmartPot

**Maxime — [MaxBarbe](https://github.com/MaxBarbe)** : projet de pot connecté, conception et essais de l'antenne dans CST, modèle mécanique du pot et captures associées. Les adaptations du projet KiCad et sa documentation ont été préparées avec l'assistance de Codex.

## Base pédagogique

Le dépôt a été initialement dupliqué à partir de [DorianDIANA/EDU_RAK_2026](https://github.com/DorianDIANA/EDU_RAK_2026). Les ressources initiales sont regroupées dans `references/EDU_RAK_2026/`, avec leur README d'origine. L'historique Git est conservé ; cette réorganisation ne réattribue pas les fichiers d'origine à SmartPot.

## Références techniques

- Texas Instruments : BQ25570, note d'application [DN038 / SWRA416](https://www.ti.com/lit/an/swra416/swra416.pdf) et géométrie de référence [SWRR082](https://www.ti.com/lit/zip/swrr082) utilisée pour l'ancienne antenne KiCad.
- RAKwireless : module RAK3172 ; documentation d'origine conservée parmi les ressources pédagogiques.
- Sensirion : SHT40 ; symboles, empreintes et modèle 3D présents dans le projet KiCad.

# Anciennes versions SmartPot

Versions antérieures à la V4, archivées le 28 octobre 2026. Elles sont conservées pour comparaison ; la carte KiCad actuelle est la [V4](../pot_fleur_v4_nouvelle_antenne/README.md). La [V5 CST](../CST/V5_ADAPTATION_868/README.md) est une proposition d’adaptation pour simulation.

|---|---|
| [pot_fleur](pot_fleur/README.md) | Première carte quatre couches et anciennes intégrations d’antenne |
| [V2 deux couches](pot_fleur_v2_2couches/README.md) | Variante deux couches, exports et contrôles historiques |

| [Anciennes instructions de reprise](REPRISE_CST_V3.md) | Historique du transfert des projets V3 |

Chaque `.cst` doit rester accompagné de son dossier de même nom lorsqu’il existe. Les résultats et hypothèses de ces modèles ne valident pas automatiquement les versions plus récentes. Les réglages locaux KiCad sont conservés sur le Mac.

Les fichiers X0 dans `../CST/ANTENNE_868_3QUARTS/` restent directement accessibles comme référence de la géométrie utilisée en V4 ; ce dossier n’est pas une autre carte KiCad active.
